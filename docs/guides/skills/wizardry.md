# Wizardry

Wizardry is the Wizard's skill. It rises from Web and Dispel Illusions, and it adds nothing to their power.

| | |
|---|---|
| Kind | Magic |
| Starting value | 1 |
| Rises from | Casting Web or Dispel Illusions; the Wizard promotion |
| Cap | [Mage cap](README.md#caps) |
| Medal | Wizard's Crest at 90: +1 Dexterity |
| Counts towards | Bio score, high scores, combat rating |

## How it rises

- **Casting** Web or Dispel Illusions rolls `random(Wizardry) = 1` while it is above 0 and below the Mage cap; see [casting](README.md#casting).
- **Promotion to Wizard** raises it to a roll of 1 to 10 if it is lower.

## What it does

Nothing reads Wizardry except the medal, the title, the scores and the combat rating. Web and Dispel Illusions use [Magery](magery.md)'s base power only.

## Connected systems

- **Spells:** see the [spells guide](../spells.md).
- **Bio titles:** Wizard (above 60 with Magery above 80).

## Differences from 1.6

- [Class promotions give their skills](../../differences-from-fso.md#class-promotions-give-their-skills): Wizard now grants Wizardry.

## Balance notes

- Wizardry has no effect on play beyond its medal, title and scores.
