# Wrath

Wrath is the school of attacking magic: Meteor, Bolt, Radar and Magic Shield. No class grants it.

| | |
|---|---|
| Kind | Magic |
| Starting value | 1 |
| Rises from | Casting Wrath spells |
| Cap | [Mage cap](README.md#caps) |
| Medal | None |
| Counts towards | Bio score, high scores, combat rating |

## How it rises

**Casting** Radar, Meteor, Magic Shield or Bolt (in any direction) rolls `random(Wrath) = 1` while it is above 0 and below the Mage cap; see [casting](README.md#casting).

## What it does

Adds to the power of Meteor, Radar, Bolt and Magic Shield: +2 above 0, then +1 above 10, 20, 30, 50, 70, 80, 90 and 97, up to +10. Magic Shield lasts 70 frames per point of power.

## Connected systems

- **Spells:** see the [spells guide](../guides/spells.md).
- **Combat:** Magic Shield reduces the spell damage you take.

## Differences from 1.6

- [Bolt and Wind Wave train their school; free fireballs train nothing](../differences-from-fso.md#bolt-and-wind-wave-train-their-school-free-fireballs-train-nothing): in 1.6 a directional Bolt never trained Wrath.
